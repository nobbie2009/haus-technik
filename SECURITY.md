# Sicherheitsmeldungen

Keine Zugangsdaten oder privaten Projektdateien in Issues oder Pull Requests veröffentlichen.
Wenn im GitHub-Repository private Sicherheitsmeldungen aktiviert sind, den Bereich
**Security → Report a vulnerability** verwenden. Andernfalls zunächst ohne technische Details
um einen privaten Meldeweg beim Repository-Verantwortlichen bitten.

Home-Technik speichert Projekte browserlokal. Projektdateien können Hauspläne, Fotos, Seriennummern
und Wartungsdaten enthalten. Der WLAN-Vorschau-Server ist für das eigene Heimnetz gedacht;
er bietet weder Benutzeranmeldung noch Zugriffskontrolle. Home-Assistant-Token werden nicht
im Projekt gespeichert.

Die Elektrosimulation ist ein vereinfachtes Planungsmodell. Ihre Ergebnisse sind keine Messung
und kein Nachweis der elektrischen Sicherheit einer realen Anlage.
